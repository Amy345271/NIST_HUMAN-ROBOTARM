# NIST_HUMAN&ROBOTARM

Repository for iterating dataset processing and labeling tools inspired by the REASSEMBLE project.

This repo will store scripts, annotation conversions, and versioned code for synchronizing and splitting multimodal recordings (human and robot arm) following the NIST assembly protocol.

Structure (initial):
- scripts/ : conversion and labeling helper scripts
- data/ : placeholder for example h5 files (not stored here)

Notes:
